# CrokPocket — приложение для Android 10–14

Компаньон для приставки CrokPocket (прошивка CrokOS).

## Что умеет
- **Файлы на приставке.** Подключается к сети «CrokPocket» (на приставке пункт «Wi-Fi»). Список папок, загрузка, скачивание на телефон, переименование, удаление, новые папки, свободное место.
- **Конвертер.** Работает средствами самого Android (MediaCodec), без ffmpeg:
  - видео (MP4, MKV, WebM, MOV, 3GP) → AVI: MJPEG до 320×240, 10–24 кадра/с + звук PCM 22050 Гц моно → `/Video`;
  - фото (JPG, PNG, HEIC, WebP, GIF) → JPEG до 640×480 с учётом поворота → `/Pictures`;
  - музыка: MP3 остаётся как есть, остальное → WAV 32 кГц моно → `/Music`.
- **Игры.** ROM раскладываются по папкам Retro-Go (`/roms/nes`, `/roms/gb`, …) по расширению. В ZIP система определяется по файлу внутри.
- **Настройки.** Wi-Fi, нейросеть, ключи, режим подключения. Приложение собирает `crokos.ini` и кладёт в корень SD-карты.
- **«Поделиться» → CrokPocket** из галереи, музыки или файлового менеджера.

## Сборка APK в Android Studio
1. Распакуйте архив и откройте папку `CrokPocketApp` (File → Open).
2. Дождитесь Gradle Sync. Studio сама скачает Gradle, Android Gradle Plugin и Android SDK 34. Если предложит обновить AGP — можно согласиться.
3. Выберите Build → Build App Bundle(s) / APK(s) → **Build APK(s)**.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
5. Скопируйте APK на телефон и установите (разрешите установку из неизвестных источников).

Сторонних библиотек нет: только стандартные API Android, язык Java 17.

## Связь с приставкой
- Приставка раздаёт открытую сеть `CrokPocket`, адрес `192.168.4.1`.
- API приставки:
  - `GET /list?dir=` → JSON `[{n,d,s}]`;
  - `GET /dl?path=`, `GET /del?path=`, `GET /mkdir?path=`;
  - `POST /upload?dir=` (multipart).
- С прошивки CrokOS от 16.10.2026 добавлены `GET /info` (версия, место на карте) и `GET /rename?from=&to=`.
- В сети приставки нет интернета, поэтому все запросы привязаны к этой Wi-Fi сети (`Network.openConnection`). Иначе Android отправил бы их через мобильный интернет.
